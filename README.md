# MobilityNews

모빌리티 산업 뉴스레터 자동화 파이프라인

## 프로젝트 구조

```
MobilityNews/
├── crawlers/      # 뉴스 수집 크롤러
├── intelligence/  # AI 기반 뉴스 분석
├── delivery/      # 뉴스레터 발송
├── config.py      # 설정 파일
├── main.py        # 메인 실행 파일
└── requirements.txt
```

## 시작하기

```bash
pip install -r requirements.txt
python main.py
```
